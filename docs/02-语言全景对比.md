# 02 · 语言全景对比

## 全景对比表

| 维度 | Java | Go | Python | Node.js | PHP |
|---|---|---|---|---|---|
| 定位 | 企业后端/中间件 | 云原生/高并发服务 | AI/数据/脚本/后端 | BFF/实时交互 | Web 服务端 |
| 类型系统 | 静态强类型 | 静态强类型(类型推导) | 动态强类型(可选注解) | 动态(TS 可静态) | 动态弱类型 |
| 执行方式 | JIT 编译(字节码) | AOT 编译(静态二进制) | 解释执行(.pyc 缓存) | JIT 编译(V8) | 解释执行(PHP8 含 JIT) |
| 运行时 | JVM | 无(单二进制) | CPython 解释器 | V8 + libuv | Zend 引擎 + PHP-FPM |
| 内存管理 | 分代 GC(可调优) | 并发 GC(自动) | 引用计数 + 循环 GC | 分代 GC | 引用计数 |
| 并发模型 | 线程 + 锁 + 异步编排 | goroutine + channel | 线程 / asyncio / 进程 | 单线程 Event Loop | 多进程 + 协程(Swoole) |
| 包管理 | Maven / Gradle | go mod | pip / poetry | npm / pnpm / yarn | composer |
| 构建 | Maven / Gradle | go build(静态) | 无(源码分发) | 无(打包工具链) | 无 |
| 常用 Web 框架 | Spring Boot | Gin / Echo / Fiber | FastAPI / Django | Express / NestJS | Laravel / Slim / Hyperf |
| ORM | MyBatis / JPA | GORM / sqlx | SQLAlchemy | Prisma / TypeORM | Eloquent / Doctrine |
| 测试 | JUnit + Mockito | go test(内置) | pytest | Jest / Vitest | PHPUnit |
| 部署形态 | JAR + JRE 镜像 | 静态二进制镜像 | 解释器 + 依赖镜像 | Node 运行时镜像 | PHP-FPM 镜像 |
| 进程管理 | 系统服务 + 容器 | 单二进制 + 容器 | 多进程管理器 | 单进程 + cluster | FPM 进程池 |
| 监控 | Actuator / JMX / Prometheus | pprof / expvar / Prometheus | prometheus_client | prom-client | FPM 状态页 |
| 学习曲线(Java 视角) | —(已知) | 低(语法近) | 低(语法简) | 中(异步心智) | 低(语法简) |
| 心智模型差异 | — | 中 | 中 | 大 | 大(生命周期) |

## 选型建议(Java 架构师视角)

| 场景 | 推荐 | 理由 |
|---|---|---|
| 高并发网关/中间件/云原生 | Go | 静态二进制、低内存、goroutine 天然适合 IO 密集 |
| AI 应用/数据处理/快速原型 | Python | 生态碾压:ML/LLM/数据分析 |
| BFF、实时推送、SSE | Node.js | 异步 IO 高效,前后端同语言 |
| 存量 Web 系统/内容站 | PHP | 生态成熟、部署简单(但新项目慎选) |
| 核心交易系统(资金/订单) | Java(不变) | 生态、稳定性、人才储备优势仍在 |

## 快速判断「这门语言要不要学」

- 你的下一个项目形态是什么?→ 对上表「场景→推荐」。
- 团队/行业趋势:云原生看 Go,AI 看 Python,BFF 看 Node。
- 求职:多语言能力是加分项,但**深度大于广度**,建议一门主语言 + 一门对照语言。
