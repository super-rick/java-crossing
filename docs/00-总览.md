# 00 · 总览

> 验证环境:本仓库为纯 Markdown 文档,不依赖构建工具;示例代码的验证环境见各语言模块头部。

## 本仓库是什么

以 Java 为锚点,系统性整理 Java 开发者迁移到 **Go / Python / Node.js / PHP** 所需的全部对应关系:语言特性、语法、数据结构、并发、IO、测试、生产框架、部署运维、监控。

不是「XX 语言入门教程」——单语言入门资料到处都是。本仓库只写一件事:**Java 开发者视角的对应关系**。

## 读者画像

- ≥1 年 Java 后端经验,熟悉 Spring Boot / JVM / Maven / JUnit 等常见工具
- 想快速上手第二种(或第三种)后端语言,用于新项目、求职或架构选型
- 需要的不是语法速查,而是「生产可用」:能写、能测、能部署、能排查

## 阅读方式

### 路径 A:快速上手一门新语言(1–2 周)

1. 读 `01-学习路径总图.md`,选定目标语言,理解核心心智差异
2. 读目标语言 `11-学习路径.md`,按 7 天路线走
3. 过程中按需查阅该语言的 01–10 模块
4. 最后对照 `examples/` 的订单服务实现,理解真实生产形态

### 路径 B:按需查阅(工作中遇到再查)

| 遇到问题 | 去这里 |
|---|---|
| 语法卡壳(循环/函数/类/错误处理) | 该语言 `02-基础语法.md` |
| 并发/异步写不对 | 该语言 `04-并发编程.md` + `topics/并发模型对比.md` |
| 集合 API 找不到对应物 | 该语言 `03-数据结构.md` |
| 选框架 / 选 ORM | 该语言 `07-生产框架.md` + `topics/Web框架生态对比.md` |
| 部署 / 容器化 / 调优 | 该语言 `08-部署运维.md` + `topics/部署形态对比.md` |
| 监控 / 日志 / 排查 | 该语言 `09-监控.md` + `topics/监控体系对比.md` |
| 报错看不懂(术语) | `GLOSSARY.md` |

### 路径 C:架构选型(横向对比)

读 `02-语言全景对比.md`(一张表看全)与 `topics/` 全部八张对比表。
