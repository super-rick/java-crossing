# Python · 03 数据结构

> 锚点:Java 集合框架(List/Map/Set/Queue)逐项对应 Python 内置数据结构。
>
> 验证环境:Python 3.11.15(实测输出)。

## 数据结构对照表

| Java | Python | 说明 |
|---|---|---|
| ArrayList | **list** `[]` | 动态数组,append/切片 |
| LinkedList | list(或 collections.deque) | deque 双端队列 |
| HashMap | **dict** `{}` | 内置哈希表 |
| LinkedHashMap | dict | **Python 3.7+ dict 保序**(插入序) |
| HashSet | **set** `{}` | 内置去重集合 |
| TreeMap/TreeSet | 无(排序用 sorted()) | sorted() 返回排序列表 |
| 数组 | tuple(不可变)/ list | tuple ≈ 不可变 list |
| Queue | collections.deque / queue.Queue | queue.Queue 线程安全 |
| Stack | list(push=append, pop=pop) | 直接支持 |
| 字符串 | str(不可变) | 与 Java String 同 |
| Optional | 可选类型 `T \| None` | 3.10+ 类型注解 |
| record | dataclass(3.7+) | ≈ Java record,极常用 |

## 完整对照示例(实测)

```python
def main():
    # list ≈ ArrayList
    nums = [1, 2, 3]
    nums.append(4)
    nums.extend([5, 6])
    print("list:", nums)
    print("slice:", nums[1:4])

    # dict ≈ HashMap
    m = {"a": 1, "b": 2}
    m["c"] = 3
    print("get-default:", m.get("missing", "default"))  # 带默认值(≈ Optional.orElse)
    print("exists:", "a" in m)
    del m["b"]
    print("len:", len(m))

    # set ≈ HashSet
    s = {1, 2, 2, 3}
    print("set:", s)

    # tuple ≈ 不可变序列(近似 record 的轻量形态)
    t = (1, "a", 3.14)
    print("tuple:", t)

    # 推导式(≈ stream().filter().map().collect())
    evens = [n for n in range(10) if n % 2 == 0]
    print("evens:", evens)


if __name__ == "__main__":
    main()
```

运行:`python main.py`
输出:

```
list: [1, 2, 3, 4, 5, 6]
slice: [2, 3, 4]
get-default: default
exists: True
len: 2
set: {1, 2, 3}
tuple: (1, 'a', 3.14)
evens: [0, 2, 4, 6, 8]
```

> ⚠️ Java 思维陷阱 1:`HashMap.get()` 返回 null 要判空——Python 的 `m.get(k, default)` 原生支持默认值,`k in m` 判断存在;直接 `m[k]` 不存在会抛 KeyError。
>
> ⚠️ Java 思维陷阱 2:用 `new ArrayList<>()` 然后 add——Python 直接字面量 `[1,2,3]`;推导式 `[f(x) for x in items]` 一行替代「循环 + 收集」(≈ stream)。
>
> ⚠️ Java 思维陷阱 3:slice 是**新列表**(拷贝),与 Go 的共享视图不同——`nums[1:4]` 返回新 list,修改不影响原列表。

## 关键补充

### dataclass ≈ Java record(生产常用)

```python
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int
    # 自动生成 __init__/__repr__/__eq__,≈ Java record

u = User("Alice", 30)
print(u)          # User(name='Alice', age=30)
print(u.name)     # 属性访问(非 getter/setter)
```

### 常用操作速查

| 场景 | Python |
|---|---|
| 排序 | `sorted(nums)` / `nums.sort()`;带 key:`sorted(users, key=lambda u: u.age)` |
| 去重保序 | `list(dict.fromkeys(items))` |
| 分组 | `itertools.groupby` / dict 手动 |
| 计数 | `collections.Counter(items)`(≈ Java 手写 Map 计数) |
| 最大/最小 | `max(nums)` / `min(nums)` |
| 合并字典 | `{**a, **b}`(3.5+)/ `a \| b`(3.9+) |
| JSON | `json.dumps/loads`(标准库,零依赖) |
