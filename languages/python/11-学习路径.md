# Python · 11 学习路径

> 锚点:给 Java 开发者的 7 天 Python 上手路线(基于本仓库模块)。
>
> 验证环境:纯文档;前置要求:已装 Python 3.11+(见 languages/python/README.md)。

## 7 天上手路线

| 天 | 任务 | 产出(可自检) | 用到的模块 |
|---|---|---|---|
| D1 | 装工具链(python + uv)+ venv + hello world | `python main.py` 跑通;理解 venv | README |
| D2 | 语法对照:缩进/变量/函数/类/异常/推导式 | 用 Python 重写一个 Java 小工具 | 02 |
| D3 | 数据结构:list/dict/set/tuple/dataclass | 实现一个 JSON 配置解析器 | 03 |
| D4 | **并发:三套模型选型练习** | 分别用 threading/asyncio/multiprocessing 实现同一任务并对比 | 04 |
| D5 | IO + 测试:文件/JSON/HTTP + pytest | 给 D2-D4 代码补 pytest(参数化+fixture),覆盖率 ≥80% | 05、06 |
| D6 | 生产框架:FastAPI + pydantic + SQLAlchemy | 写 CRUD API(参考 examples/python-order-service) | 07 |
| D7 | 部署:gunicorn 多 worker + Dockerfile + py-spy | 起多进程服务,curl /metrics 看得到指标 | 08、09 |

**验收标准(D7 结束)**:独立完成「带并发扣减的订单服务」的编写、测试、部署、监控——即 `examples/python-order-service` 全过程。

## 实战项目建议(顺序递进)

1. **命令行工具**:日志分析/文件整理(练语法 + 标准库)
2. **数据脚本**:CSV/JSON 处理 + 简单报表(练数据结构 + pandas 入门)
3. **FastAPI 服务**:订单 CRUD + 并发扣减(练生产形态,即 examples/ 契约)
4. **AI 应用**:接一个 LLM API 做工具(练 AI 生态,Python 独有价值)

## 常见问题

| 问题 | 答案 |
|---|---|
| 学 Python 要多久 | 语法 2-3 天;并发选型 1 周;AI/数据生态持续积累 |
| Java 经验有帮助吗 | 极大:工程概念(测试/部署/监控)全部可迁移,只换语法 |
| Python 性能差怎么办 | 性能瓶颈用 C 扩展/numpy/Cython;服务场景靠架构(缓存/队列)而非语言 |
| 学 Python 还是 Go 先 | 求职 AI/数据 → Python;云原生/高并发 → Go;两门都值得(先一门主攻) |
