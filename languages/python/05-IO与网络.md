# Python · 05 IO 与网络

> 锚点:Java 的 java.io/NIO/HttpClient/Jackson 对应 Python 的 open/json/requests/httpx 生态。
>
> 验证环境:Python 3.11.15(实测输出)。

**一句话:Python 的标准库把「文件 + JSON」做到一行搞定;HTTP 客户端用第三方 requests/httpx;异步 IO 用 asyncio(注意别混用同步库)。**

## IO 对照表

| 场景 | Java | Python |
|---|---|---|
| 读文件 | Files.readAllBytes / BufferedReader | `open(path).read()` / pathlib.Path.read_text() |
| 写文件 | Files.write | `open(path, "w").write(...)`(with 自动关闭) |
| 流式读 | BufferedReader.readLine | `for line in f:`(迭代器) |
| JSON | Jackson / Gson | **json(标准库)** / pydantic |
| HTTP 客户端 | RestTemplate / HttpClient | requests(同步)/ httpx(同步+异步) |
| 网络服务 | Spring Boot / Netty | FastAPI / aiohttp |
| 序列化 | protobuf / Java 序列化 | pickle(勿用于对外)/ protobuf |

## 完整对照示例(实测)

```python
import json
import os


class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def to_dict(self):
        return {"name": self.name, "age": self.age}


def main():
    # 文件读写(with 语句自动关闭,≈ try-with-resources)
    with open("godoc-py-data.txt", "w", encoding="utf-8") as f:
        f.write("hello file")
    with open("godoc-py-data.txt", "r", encoding="utf-8") as f:
        content = f.read()
    print("file:", content)
    os.remove("godoc-py-data.txt")

    # JSON 序列化(≈ ObjectMapper.writeValueAsString)
    u = User("Alice", 30)
    j = json.dumps(u.to_dict(), ensure_ascii=False)
    print("json:", j)

    # 反序列化(≈ readValue)
    data = json.loads(j)
    print("unmarshal:", data["name"], data["age"])


if __name__ == "__main__":
    main()
```

运行:`python main.py`
输出:

```
file: hello file
json: {"name": "Alice", "age": 30}
unmarshal: Alice 30
```

> ⚠️ Java 思维陷阱 1:忘记关闭文件——Python 的 `with open(...)` 自动关闭(≈ try-with-resources),永远用它;`f.read()` 读完要意识到文件指针。
>
> ⚠️ Java 思维陷阱 2:JSON 字段命名——Python 惯例 snake_case(`user_name`),Java 是 camelCase;跨语言对接时用 `json` 参数别名或 pydantic `alias` 映射。
>
> ⚠️ Java 思维陷阱 3:用 requests 时开太多连接——requests 默认会话复用差,生产用 `requests.Session()` 或 httpx 连接池(≈ HttpClient 连接池思维)。

## HTTP 客户端对比

```python
# requests(同步,≈ RestTemplate)
import requests
resp = requests.get("https://api.example.com/orders/1", timeout=5)
print(resp.status_code, resp.json())  # resp.json() ≈ Jackson 反序列化
```

```python
# httpx(异步,≈ 响应式 HttpClient)
import httpx, asyncio

async def main():
    async with httpx.AsyncClient(timeout=5) as client:
        resp = await client.get("https://api.example.com/orders/1")
        print(resp.json())

asyncio.run(main())
```

## 异步 IO 注意事项

- asyncio 事件循环里**禁止同步阻塞调用**(requests、标准库文件 IO 的同步版本)。
- 必须用:httpx(异步 HTTP)、`asyncio.to_thread(fn)`(把同步调用丢线程池,≈ 3.9+)。
- 判断:`await` 关键字只出现在 async 函数里;同步库调用出现在 async 函数里就是 bug 信号。
