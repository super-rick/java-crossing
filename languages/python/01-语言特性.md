# Python · 01 语言特性

> 锚点:Java 的「静态强类型 + 编译 + 分代 GC + OO」对应 Python 的「动态类型 + 解释执行 + 引用计数 + 鸭子类型」。
>
> 验证环境:Python 3.11.15(实测输出)。

## 范式对比

| 维度 | Java | Python |
|---|---|---|
| 类型系统 | 静态强类型(编译期检查) | **动态强类型**(运行时检查) |
| 执行方式 | 编译 → 字节码 → JIT | **解释执行**(.pyc 字节码缓存) |
| 内存管理 | 分代 GC(可调优) | **引用计数 + 循环 GC** |
| 并发 | 多线程(真并行) | 线程受 **GIL** 限制;多进程/异步补充 |
| OO | 类继承 + 接口 + 泛型 | 类继承 + 鸭子类型 + Protocol |
| 设计哲学 | 框架驱动、企业规范 | **「显式优于隐式」+ 实用主义** |
| 代码风格 | 大括号 + 分号 | **缩进即语法**(PEP 8) |
| 生态 | 企业级全家桶 | 数据/AI/脚本领域统治 |

## 关键差异

### 1. 动态类型:灵活与风险并存

```python
x = 1        # int
x = "str"    # 直接变成字符串,编译不报错
x = [1, 2]   # 又变成 list
```

- Java:类型编译期锁定,IDE 强提示。
- Python:类型运行时才检查,小脚本极快;大项目靠 **类型注解 + mypy** 补回可维护性(见 07 模块)。

> ⚠️ Java 思维陷阱:以为 Python 无法静态检查——现代 Python 用类型注解(`def f(x: int) -> str:`)配合 mypy/pyright,CI 里跑 `mypy .` 就能拿到接近 Java 的编译期保护。大项目不写注解是反模式。

### 2. GIL:Python 线程的「紧箍咒」

- CPython 有 **GIL(全局解释器锁)**:同一时刻只有一个线程执行 Python 字节码。
- 后果:多线程**无法利用多核做 CPU 密集计算**;IO 密集(等待网络/磁盘)时线程切换没问题。
- 解法:CPU 密集用 `multiprocessing`(多进程);IO 密集用 `asyncio` 或 threading。
- Python 3.13 起提供 free-threading(实验性,无 GIL 构建),但生产主流仍是 GIL 版。

### 3. 引用计数:内存释放是「确定性」的

```python
def f():
    data = [1, 2, 3]  # 函数返回后,引用计数归零 → 立即释放
```

- 与 JVM 分代 GC 的最大区别:Python 对象**引用归零即释放**,无「GC 暂停」概念,也没有 JVM 式的调优参数。
- 循环引用(A→B→A)由分代回收器兜底,可能延迟释放。
- 心智转换:Java 靠 GC「兜底一切」;Python 里长期持有引用(全局缓存、闭包)= 内存泄漏。

### 4. 缩进即语法

```python
def f(x):
    if x > 0:
        return "positive"   # 缩进是语法,不是风格
    return "non-positive"
```

- Java 缩进坏了只是风格问题;Python 缩进错了**直接语法错误**。
- 好处:强制统一风格,团队代码天然整洁;坏处:复制粘贴/混合 tab-空格会炸。

### 5. 鸭子类型 vs 接口

```python
class Dog:
    def speak(self):
        return "Woof"

class Robot:
    def speak(self):
        return "Beep"

def announce(obj):     # 不需要 implements 任何接口
    print(obj.speak()) # 有 speak 方法就能传进来

announce(Dog())
announce(Robot())
```

- Java 接口是「契约声明」;Python 是「能调就行」——比 Go 的隐式接口更彻底(Go 仍有静态检查)。
- 需要契约时:abc.ABC 抽象基类 或 typing.Protocol(结构类型)。

### 6. 语言细节对照

| 特性 | Java | Python |
|---|---|---|
| 变量 | `int x = 1;` | `x = 1`(无类型声明) |
| 常量 | `static final` | 约定全大写 `MAX_SIZE = 10`(无强制) |
| 包/模块 | package + import | 文件即模块,import 按文件路径 |
| 可见性 | public/private/protected | **约定**:`_x` 私有,`__x` 名称修饰(无强制) |
| 多返回值 | 无 | 元组 `return a, b` |
| 重载 | 支持(方法重载) | 无重载,默认参数替代 |
| main 入口 | public static void main | `if __name__ == "__main__":` |

## 小结

Python 对 Java 开发者的核心冲击:类型不锁、线程受限(GIL)、缩进是语法。接受这三点后,Python 的开发效率优势会立刻显现——尤其 AI/数据场景,它是无可替代的入口语言。
