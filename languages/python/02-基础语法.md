# Python · 02 基础语法

> 锚点:Java 的语法体系(变量/控制流/方法/类/异常)逐项对应 Python 的写法。
>
> 验证环境:Python 3.11.15(实测输出)。

## 语法对照表

| 特性 | Java | Python | 差异要点 |
|---|---|---|---|
| 变量 | `int x = 1;` | `x = 1` | 无类型、无分号、无大括号;注释用 # |
| 常量 | `static final` | `MAX = 10`(约定) | 无强制只读 |
| if | `if (a > b) { }` | `if a > b:` | 冒号 + 缩进;`elif` 代替 else if |
| 循环 | for/while | `for x in iterable:` / `while cond:` | 无 C 风格 for;range() 生成序列 |
| switch | `switch(x){ case 1: }` | `match x: case 1:`(3.10+) | 新语法;旧代码常用 if/elif 或 dict |
| 函数 | 方法需在类中 | 顶层 `def` | 默认参数/可变参数 `*args, **kwargs` |
| 多返回值 | 无 | `return a, b`(元组) | 天然支持 |
| 异常 | try/catch/finally | try/except/finally + `raise` | **与 Java 同源**,上手最平滑 |
| 类 | class + new | `class User:` + `User()` | `__init__` 构造;无 new 关键字 |
| 接口 | interface/implements | 鸭子类型 / ABC / Protocol | 无显式实现 |
| 泛型 | `<T>` | 类型注解 `list[int]`(3.9+) | 运行时无强制 |
| 字符串 | String 不可变 | str 不可变 | f-string 格式化 |
| 包 | package + import | import / from ... import | 文件即模块 |

## 完整对照示例(实测)

```python
# 动态类型/控制流/函数/类/异常
def divide(a, b):
    if b == 0:
        raise ValueError("division by zero")  # 异常机制(与 Java 同源)
    return a / b


def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"


class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def birthday(self):
        self.age += 1

    def __str__(self):
        return f"{self.name}({self.age})"


if __name__ == "__main__":
    # 动态类型:变量无需声明类型
    x = 1
    x = "now a string"

    # 控制流
    for i in range(3):
        print("for:", i)

    # 列表推导(Java stream 的对应物)
    squares = [i * i for i in range(5)]
    print("squares:", squares)

    # 异常
    try:
        print(divide(10, 0))
    except ValueError as e:
        print("error:", e)

    # 类
    u = User("Alice", 30)
    u.birthday()
    print("user:", u)
    print("greet:", greet("Go"))
```

运行:`python main.py`
输出:

```
for: 0
for: 1
for: 2
squares: [0, 1, 4, 9, 16]
error: division by zero
user: Alice(31)
greet: Hello, Go!
```

> ⚠️ Java 思维陷阱 1:写 Java 风格三目 `a ? b : c`——Python 用 `b if cond else c`(或直接 if-else)。
>
> ⚠️ Java 思维陷阱 2:重载方法——Python 没有重载,用默认参数实现同一效果:`def f(x, mode="a")`。
>
> ⚠️ Java 思维陷阱 3:for 循环用索引——Python 惯例直接迭代:`for item in items`,要索引用 `enumerate(items)`。
>
> ⚠️ Java 思维陷阱 4:`new` 关键字——Python 直接 `User()`;构造逻辑放 `__init__`。

## 常用写法对照

| 场景 | Java | Python |
|---|---|---|
| 字符串格式化 | String.format("%s-%d", s, i) | `f"{s}-{i}"`(f-string) |
| 遍历带索引 | for (int i=0; i<n; i++) | `for i, v in enumerate(items)` |
| 条件表达式 | 三目?无,if-else | `x = a if cond else b` |
| 判空 | `x == null` | `x is None` |
| 列表转字符串 | String.join | `",".join(items)` |
| 类型转换 | (int) str / Integer.parseInt | `int("123")` |
| 数组长度 | arr.length / list.size() | `len(items)` |
| 日志占位 | log.info("x={}", x) | `logging.info("x=%s", x)`(或 f-string) |
