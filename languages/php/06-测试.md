# PHP · 06 测试

> 锚点:Java 的 JUnit 5 + Mockito + JaCoCo 对应 PHP 的 PHPUnit + 内置 mock + 覆盖率。
>
> 验证环境:PHP 8.4.24;PHPUnit 11.x(经 composer 安装)。

**一句话:PHPUnit 与 JUnit 血缘最近——命名、断言、数据提供者(≈@ParameterizedTest)、mock 用法几乎一一对应,Java 开发者上手成本最低。**

## 测试对照表

| 维度 | Java | PHP |
|---|---|---|
| 框架 | JUnit 5 | **PHPUnit** |
| 安装 | Maven 依赖 | `composer require --dev phpunit/phpunit` |
| 测试类 | @Test 注解方法 | `class XTest extends TestCase` + `testXxx()` 方法 |
| 断言 | Assertions.assertEquals | `$this->assertSame($expected, $actual)` |
| 参数化 | @ParameterizedTest | **@dataProvider**(注解,≈ 同名) |
| 生命周期 | @BeforeEach/@AfterEach | setUp()/tearDown()(同名方法) |
| Mock | Mockito | PHPUnit mock(内置,`createMock`) |
| 覆盖率 | JaCoCo | `--coverage-html`(需 Xdebug/PCOV) |
| 异常断言 | assertThrows | `expectException(InvalidArgumentException::class)` |

## 完整对照示例

被测代码 `src/Calc.php`:

```php
<?php
namespace App;

class Calc {
    public function add(int $a, int $b): int {
        return $a + $b;
    }

    public function divide(int $a, int $b): float {
        if ($b === 0) {
            throw new \InvalidArgumentException("division by zero");
        }
        return $a / $b;
    }
}
```

测试代码 `tests/CalcTest.php`:

```php
<?php
namespace App;

use PHPUnit\Framework\TestCase;

class CalcTest extends TestCase {
    /** @dataProvider addProvider */
    public function testAdd(int $a, int $b, int $expected): void {
        $this->assertSame($expected, (new Calc())->add($a, $b));
    }

    public static function addProvider(): array {
        return [
            "正常" => [1, 2, 3],
            "零值" => [0, 0, 0],
            "负数" => [-1, 1, 0],
        ];
    }

    public function testDivideNormal(): void {
        $this->assertSame(5.0, (new Calc())->divide(10, 2));
    }

    public function testDivideZero(): void {
        $this->expectException(\InvalidArgumentException::class);
        (new Calc())->divide(1, 0);
    }
}
```

运行:`vendor/bin/phpunit tests/CalcTest.php`

> ⚠️ Java 思维陷阱 1:找 @Test 注解——PHPUnit 靠「类名 Test 后缀 + test 方法前缀」命名约定,无注解(8.x 有属性可选,但惯例是命名)。
>
> ⚠️ Java 思维陷阱 2:assertEquals vs assertSame——`assertEquals(1, "1")` 通过(弱类型比较),`assertSame` 才校验类型;**PHP 测试默认用 assertSame**。
>
> ⚠️ Java 思维陷阱 3:数据提供器命名——@dataProvider 指向的方法**必须是 static**(PHPUnit 10+ 要求),返回「用例名 => 参数数组」格式。

## Mock 示例(内置,≈ Mockito)

```php
$mock = $this->createMock(PaymentGateway::class);
$mock->method('charge')
     ->with(100.0)
     ->willReturn(['ok' => true]);

$this->assertTrue($orderService->pay($mock, 100.0));
```

## 覆盖率

```bash
# 需启用 Xdebug 或 PCOV 扩展
vendor/bin/phpunit --coverage-html coverage/ --coverage-text
```

CI 门槛:`--coverage-text` 解析 + fail_under(或 CI 工具配置)。
