# PHP · 02 基础语法

> 锚点:Java 的语法体系逐项对应 PHP 的写法。
>
> 验证环境:PHP 8.4.24(实测输出)。

## 语法对照表

| 特性 | Java | PHP | 差异要点 |
|---|---|---|---|
| 变量 | `int x = 1;` | `$x = 1;` | **所有变量带 $**;无类型声明(可加) |
| 常量 | static final | `const MAX = 10;` | 8.1+ 支持类常量可见性 |
| 输出 | System.out.println | `echo` / `print` | 脚本语言,直接输出 |
| 字符串 | 拼接 + format | 双引号插值 `"Hi, $name"` + 拼接 `.` | **`.` 是拼接,`+` 是算术** |
| if | `if (a > b) { }` | 同(也支持 `:` 替代式) | 语法相似,上手最快 |
| for/foreach | for / for-each | for / `foreach ($arr as $v)` | foreach 是主力 |
| 函数 | 方法在类中 | `function f($a, $b): int {}` | 顶层函数 + 类型声明(8.0+) |
| 类 | class + 泛型 | class + trait | trait 复用(≈ 组合) |
| 异常 | try/catch/finally | try/catch/finally + throw | **与 Java 同源** |
| 数组 | 集合框架 | **array(语法糖巨多)** | 见 03 模块 |
| 命名空间 | package | namespace + use | composer PSR-4 自动加载 |
| 空值 | null / Optional | null / `??` / `?->` | ?? ≈ orElse;?-> 空安全调用 |

## 完整对照示例(实测)

```php
<?php
declare(strict_types=1);

function divide(float $a, float $b): float {
    if ($b === 0.0) {
        throw new InvalidArgumentException("division by zero");
    }
    return $a / $b;
}

class User {
    public function __construct(
        public string $name,
        public int $age,
    ) {}

    public function birthday(): void {
        $this->age++;
    }

    public function __toString(): string {
        return "{$this->name}({$this->age})";
    }
}

// 动态类型(弱类型:$x 从 int 变 string)
$x = 1;
$x = "now a string";

for ($i = 0; $i < 3; $i++) {
    echo "for: $i\n";
}

$squares = array_map(fn($n) => $n * $n, [1, 2, 3, 4, 5]);
echo "squares: " . json_encode($squares) . "\n";

try {
    echo divide(10, 0);
} catch (InvalidArgumentException $e) {
    echo "error: " . $e->getMessage() . "\n";
}

$u = new User("Alice", 30);
$u->birthday();
echo "user: $u\n";
echo "type: " . gettype($x) . "\n";
```

运行:`php main.php`
输出:

```
for: 0
for: 1
for: 2
squares: [1,4,9,16,25]
error: division by zero
user: Alice(31)
type: string
```

> ⚠️ Java 思维陷阱 1:`.` 与 `+`——PHP 的字符串拼接是 `.`(`"a" . "b"`),`+` 是算术(会做类型转换)。
>
> ⚠️ Java 思维陷阱 2:忘记 `$` 前缀——PHP 所有变量必须 `$name`,方法参数/属性同理。
>
> ⚠️ Java 思维陷阱 3:弱类型陷阱——`1 + "2"` 得 3;生产系统务必 `declare(strict_types=1);` + 类型声明,把 PHP 当弱类型用是旧时代做法。
>
> ⚠️ Java 思维陷阱 4:构造器——PHP 8 构造器属性提升 `public function __construct(public string $name) {}` 等价于 Java 的「字段 + 构造器赋值 + getter」一条龙。

## 常用写法对照

| 场景 | Java | PHP |
|---|---|---|
| 字符串拼接 | `a + b`(重载) | `$a . $b` / `"{$a}-{$b}"` |
| 判空给默认 | Optional.orElse | `$x ?? "default"` |
| 空安全调用 | (需判空) | `$user?->getName()`(8.0+) |
| 遍历 Map | entrySet | `foreach ($map as $k => $v)` |
| 类型转换 | Integer.parseInt | `(int)"123"` / intval() |
| 数组转 JSON | ObjectMapper | `json_encode($arr)` |
| 列表映射 | stream().map() | `array_map(fn($x) => ..., $arr)` |
| 过滤 | stream().filter() | `array_filter($arr, fn($x) => ...)` |
| 类常量 | static final | `const` / `define()` |
