# PHP · 11 学习路径

> 锚点:给 Java 开发者的 7 天 PHP 上手路线(基于本仓库模块)。
>
> 验证环境:纯文档;前置要求:已装 PHP 8.4 + composer(见 languages/php/README.md)。

## 7 天上手路线

| 天 | 任务 | 产出(可自检) | 用到的模块 |
|---|---|---|---|
| D1 | 装 PHP + composer + 跑通脚本 | `php -S localhost:8080` 起开发服务器 | README |
| D2 | 语法对照:$变量/控制流/函数/类/strict_types | 用 PHP 重写一个 Java 小工具 | 02 |
| D3 | 数据结构:array 三合一 + 常用函数 | 实现一个 JSON 配置解析器 | 03 |
| D4 | **生命周期模型**:FPM 进程隔离实验 | 连续请求验证 static 不跨请求保留 | 01、04 |
| D5 | IO + 测试:文件/JSON/HTTP + PHPUnit | 给 D2-D4 写 PHPUnit(数据提供者) | 05、06 |
| D6 | 生产框架:Laravel 或 Slim | 写 CRUD API(参考 examples/php-order-service) | 07 |
| D7 | 部署:FPM + nginx + OPcache + 状态页 | 配出 FPM status,看懂 listen queue | 08、09 |

**验收标准(D7 结束)**:独立完成「带幂等支付的订单服务」的编写、测试、FPM 部署、状态页监控——即 `examples/php-order-service` 全过程。

## 实战项目建议(顺序递进)

1. **脚本工具**:日志分析/数据清洗(练语法 + 数组函数)
2. **CRUD 服务**:Slim 4 API + PDO(练生产形态,即 examples/ 契约)
3. **Laravel 全栈**:带 Blade 页面的管理系统(练全家桶)
4. **协程进阶**:Hyperf 高并发服务(对照 Java 线程模型)
