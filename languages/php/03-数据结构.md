# PHP · 03 数据结构

> 锚点:Java 集合框架(List/Map/Set)对应 PHP 的**一个类型:array**(三合一)。
>
> 验证环境:PHP 8.4.24(实测输出)。

**一句话:PHP 的 array 同时是 ArrayList、HashMap、HashSet——同一个类型三种用法,这是 PHP 与 Java 集合框架最大的语法差异。**

## 数据结构对照表

| Java | PHP | 说明 |
|---|---|---|
| ArrayList | `array`(数字索引) | `$list[] = $v` 追加 |
| HashMap | `array`(字符串键) | 保插入序(同 Python dict) |
| HashSet | `array`(值 + array_unique) | 无专门类型,用 array 模拟 |
| TreeMap | `array` + ksort() | 排序函数 |
| Queue | `array` + array_shift/array_push | SplQueue 有专门类 |
| Stack | `array` + array_push/array_pop | SplStack |
| 字符串 | string | 同 Java(不可变) |
| 记录 | class / 关联数组 | 轻量用关联数组 |
| Optional | `??` / `?->` | 见 02 模块 |

## 完整对照示例(实测)

```php
$list = [1, 2, 3]; // 列表(≈ ArrayList)
$list[] = 4; // append
echo "list: " . json_encode($list) . "\n";
echo "slice: " . json_encode(array_slice($list, 1, 2)) . "\n";

$map = ["a" => 1, "b" => 2]; // 映射(≈ HashMap,保插入序)
$map["c"] = 3;
echo "map get default: " . ($map["missing"] ?? "default") . "\n"; // ?? ≈ orElse
echo "map has: " . (array_key_exists("a", $map) ? "true" : "false") . "\n";
unset($map["b"]);
echo "map count: " . count($map) . "\n";

$set = array_unique([1, 2, 2, 3]); // ≈ HashSet(用 array 模拟)
echo "set: " . json_encode(array_values($set)) . "\n";

// 高阶函数(≈ stream().filter())
$evens = array_values(array_filter([1, 2, 3, 4, 5, 6], fn($n) => $n % 2 === 0));
echo "evens: " . json_encode($evens) . "\n";
```

运行:`php main.php`
输出:

```
list: [1,2,3,4]
slice: [2,3]
map get default: default
map has: true
map count: 2
set: [1,2,3]
evens: [2,4,6]
```

> ⚠️ Java 思维陷阱 1:`HashMap.get()` 返回 null → PHP 的 `$map["missing"]` 会**报错**(undefined key),必须 `$map["missing"] ?? "default"` 或 `array_key_exists` 判断。
>
> ⚠️ Java 思维陷阱 2:类型混淆——同一个 array 变量里可能混着数字键和字符串键(比如 `$arr = [1, 2, "a" => 3]`),遍历时 `array_keys` 能看出键类型;API 边界用 json 序列化时键类型会影响输出,注意一致性。
>
> ⚠️ Java 思维陷阱 3:array 是「值类型」语义——PHP 数组赋值是**拷贝**(写时复制),`$b = $a; $b[] = 1;` 不影响 $a;要引用用 `&$b = &$a` 或对象。

## 关键补充

### 常用操作速查

| 场景 | PHP |
|---|---|
| 排序 | `sort($arr)` / `ksort($map)` / `usort($arr, fn($a,$b) => ...)` |
| 取最大/最小 | `max($arr)` / `min($arr)` |
| 求和 | `array_sum($arr)` |
| 去重 | `array_unique($arr)` |
| 分组 | `array_group`(无内置,foreach 手动) |
| 合并数组 | `array_merge($a, $b)` / `$a + $b`(键合并语义不同!) |
| 查找 | `in_array($v, $arr)` / `array_search` |
| 转 JSON | `json_encode($arr)`(注意中文默认转义,加 JSON_UNESCAPED_UNICODE) |
| 反转 | `array_reverse($arr)` |

### 集合操作与 Java 的对应

```php
// ≈ stream().filter().map().collect(toList())
$result = array_map(
    fn($u) => $u['name'],
    array_filter($users, fn($u) => $u['age'] >= 18)
);
```

- Java 的一长串 stream 链 → PHP 的 array_map/array_filter 嵌套(从右往左读)。
- 复杂管道可读性差时,用 foreach 手动写更清晰——PHP 社区不排斥命令式。
