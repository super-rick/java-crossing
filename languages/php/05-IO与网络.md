# PHP · 05 IO 与网络

> 锚点:Java 的 java.io/HttpClient/Jackson 对应 PHP 的 file 函数族 + curl + json_encode/decode。
>
> 验证环境:PHP 8.4.24(实测输出)。

**一句话:PHP 是「脚本语言基因」——文件/JSON 都是函数式一行调用,HTTP 客户端靠 curl 扩展或 Guzzle 库。**

## IO 对照表

| 场景 | Java | PHP |
|---|---|---|
| 读文件 | Files.readAllBytes | `file_get_contents($path)` |
| 写文件 | Files.write | `file_put_contents($path, $data)` |
| 流式读 | BufferedReader | `fopen + fgets` / SplFileObject |
| JSON 序列化 | Jackson | `json_encode($arr)` |
| JSON 反序列化 | readValue | `json_decode($json, true)` |
| HTTP 客户端 | HttpClient | **Guzzle**(库)/ curl 扩展 |
| HTTP 服务端 | Spring Boot | **PHP 无常驻服务**——FPM + nginx 处理请求 |
| 上传文件 | MultipartFile | `$_FILES` 超全局 |
| 会话 | Session(容器管理) | `$_SESSION`(FPM 文件/Redis 存储) |

## 完整对照示例(实测)

```php
<?php
class User {
    public function __construct(
        public string $name,
        public int $age,
    ) {}
}

// 文件读写(≈ Files.readAllBytes / Files.write)
file_put_contents("godoc-php-data.txt", "hello file");
$content = file_get_contents("godoc-php-data.txt");
echo "file: $content\n";
unlink("godoc-php-data.txt");

// JSON(≈ ObjectMapper)
$u = new User("Alice", 30);
$j = json_encode($u);
echo "json: $j\n";
$data = json_decode($j, true); // true = 关联数组
echo "unmarshal: {$data['name']} {$data['age']}\n";
```

运行:`php main.php`
输出:

```
file: hello file
json: {"name":"Alice","age":30}
unmarshal: Alice 30
```

> ⚠️ Java 思维陷阱 1:文件操作的错误处理——`file_get_contents` 失败返回 false(不是异常!),要 `if ($content === false)` 判断;生产用 `try { } catch (Throwable $e)` 包起来或检查返回值。
>
> ⚠️ Java 思维陷阱 2:json_decode 的返回形态——不加 `true` 返回对象(stdClass),加了返回关联数组;**类型不一致是经典 bug 来源**(`$data->name` vs `$data['name']`)。
>
> ⚠️ Java 思维陷阱 3:编码——json_encode 默认把中文转成 `\uXXXX`,API 对接要加 `JSON_UNESCAPED_UNICODE`。

## HTTP 客户端(Guzzle ≈ HttpClient)

```php
use GuzzleHttp\Client;

$client = new Client(['timeout' => 5.0]);
$resp = $client->get('https://api.example.com/orders/1');
$data = json_decode($resp->getBody(), true); // ≈ Jackson 反序列化
```

## 网络请求处理(PHP 特有:超全局变量)

```php
// 请求参数直接可用(≈ Spring 自动绑定参数)
$name = $_GET['name'] ?? 'world';     // GET 参数(≈ @RequestParam)
$body = json_decode(file_get_contents('php://input'), true); // POST JSON 体(≈ @RequestBody)
$method = $_SERVER['REQUEST_METHOD']; // 请求方法
```

- 没有「路由映射到方法」的概念——**每个 URL 直接对应一个 .php 文件**(或经框架路由)。
- 心智转换:Java 的 Controller 方法 → PHP 的「请求入口文件/框架路由处理器」。

## 会话与请求上下文

```php
session_start();                      // ≈ 容器会话管理
$_SESSION['user_id'] = 123;           // 跨请求保留(默认文件存储,生产用 Redis)
```

- 传统模式会话依赖 FPM 的 cookie 机制;分布式部署必须把 session 存 Redis(与 Java 的 session 外部化同理)。
