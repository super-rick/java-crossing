# Node.js · 02 基础语法

> 锚点:Java 的语法体系(变量/控制流/方法/类/异常)逐项对应 JavaScript 的写法。
>
> 验证环境:Node 22.23.0(实测输出)。

## 语法对照表

| 特性 | Java | JavaScript | 差异要点 |
|---|---|---|---|
| 变量 | `int x = 1;` | `let x = 1;` / `const` | const 是绑定不可变(≈ final);var 是旧语法(勿用) |
| 常量 | static final | `const MAX = 10` | 对象内属性仍可变(浅冻结) |
| if | `if (a > b) { }` | 同 | 括号保留(与 Go/Python 不同) |
| for | for/while | `for...of`(迭代)/ for/while | 数组用 `for (const x of arr)` |
| 函数 | 方法/重载 | **箭头函数 `(n) => n*n`** | 一等公民,可作参数传递 |
| 类 | class + 继承 | class(语法糖) | 底层是原型链 |
| 异常 | try/catch/finally | try/catch/finally + throw | **异步也要 try/catch(在 async 函数内)** |
| 空值 | null / Optional | null / undefined | `??` 空值合并 ≈ orElse |
| 相等 | == 值比较 | `===` 严格相等 | **永远用 ===** |
| 接口 | interface | 无(TS 有) | 鸭子类型 |
| 模块 | import package | require / import | CJS 与 ESM 两套 |

## 完整对照示例(实测)

```js
// 动态类型
let x = 1;
x = "now a string";

// 箭头函数 ≈ lambda
const square = (n) => n * n;

// 解构(≈ Java 无直接对应,类似 pattern)
const [a, b] = [1, 2];
const { name, age } = { name: "Alice", age: 30 };

// 类
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  birthday() {
    this.age += 1;
  }
  toString() {
    return `${this.name}(${this.age})`;
  }
}

// 异步(核心!)≈ CompletableFuture
async function fetchData() {
  return new Promise((resolve) => setTimeout(() => resolve("data"), 50));
}

async function main() {
  for (let i = 0; i < 3; i++) console.log("for:", i);
  console.log("square:", square(5));
  console.log("destruct:", a, b, name, age);
  const u = new User("Alice", 30);
  u.birthday();
  console.log("user:", u.toString());
  const d = await fetchData(); // ≈ Future.get()
  console.log("await:", d);
  const [r1, r2] = await Promise.all([fetchData(), fetchData()]); // ≈ allOf
  console.log("all:", r1, r2);
  console.log("typeof:", typeof x); // 动态类型证据
}

main();
```

运行:`node main.js`
输出:

```
for: 0
for: 1
for: 2
square: 25
destruct: 1 2 Alice 30
user: Alice(31)
await: data
all: data data
typeof: string
```

> ⚠️ Java 思维陷阱 1:`==` 比较——JS 的 `==` 会做类型转换(`1 == "1"` 为 true),**必须用 `===`**。
>
> ⚠️ Java 思维陷阱 2:`var` 声明——函数作用域 + 可重复声明,是历史包袱;新代码只用 `let`/`const`。
>
> ⚠️ Java 思维陷阱 3:同步写法调用异步函数——`fetchData()` 不 await 返回的是 Promise 不是结果;async 函数里的每个 IO 都要 await。
>
> ⚠️ Java 思维陷阱 4:null 与 undefined 两个空值——`??` 只对 null/undefined 生效(`0 ?? "x"` = 0),`||` 会把 0/空串也替换掉,别混用。

## 常用写法对照

| 场景 | Java | JavaScript |
|---|---|---|
| 字符串模板 | String.format / 拼接 | 模板字符串 `` `${a}-${b}` `` |
| 遍历数组 | for-each | `for (const v of arr)` / `arr.forEach(v => ...)` |
| 过滤+映射 | stream().filter().map() | `arr.filter(f).map(g)`(链式) |
| 判空给默认 | Optional.orElse | `x ?? "default"` |
| 类型转换 | Integer.parseInt | `Number("123")` / `parseInt("123")` |
| 对象转 JSON | ObjectMapper | `JSON.stringify(obj)`(原生) |
| 深拷贝 | (序列化/库) | `structuredClone(obj)`(原生,Node 17+) |
| 多线程局部 | ThreadLocal | 无(单线程,无需) |
