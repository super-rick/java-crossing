# Node.js · 03 数据结构

> 锚点:Java 集合框架(List/Map/Set)逐项对应 JS 的 Array/Map/Set/Object。
>
> 验证环境:Node 22.23.0(实测输出)。

## 数据结构对照表

| Java | JavaScript | 说明 |
|---|---|---|
| ArrayList | **Array** `[]` | push/pop/shift/unshift,动态数组 |
| HashMap | **Map** | 键可为任意类型,保插入序;`get/set/has/delete` |
| LinkedHashMap | Map | **保插入序**(同 Python dict) |
| HashSet | **Set** | 自动去重,保序 |
| 数组(原始) | TypedArray | 二进制场景 |
| 轻量记录 | **Object** `{}` | 无 class 的键值容器(注意与 Map 区别) |
| Queue | Array(shift 慢)/ 队列库 | 高频队列场景用专门实现 |
| Stack | Array(push/pop) | 直接支持 |
| record | class / 普通对象 | 无内建 record,TS 有 interface |
| Optional | `??` 空值合并 | 语义最接近 |

## 完整对照示例(实测)

```js
const arr = [1, 2, 3];
arr.push(4); // ≈ ArrayList.add
const slice = arr.slice(1, 3); // ≈ subList(注意:新数组,非视图)
console.log("arr:", arr, "slice:", slice);

const m = new Map([
  ["a", 1],
  ["b", 2],
]);
m.set("c", 3);
console.log("map get default:", m.get("missing") ?? "default"); // ?? ≈ orElse
console.log("map has:", m.has("a"));
m.delete("b");
console.log("map size:", m.size);

const s = new Set([1, 2, 2, 3]);
console.log("set:", [...s]);

const obj = { name: "Alice", age: 30 }; // ≈ 轻量 record(无 class)
console.log("obj:", obj.name);

// 高阶函数(≈ stream().filter().map())
const evens = [1, 2, 3, 4, 5, 6].filter((n) => n % 2 === 0).map((n) => n * 10);
console.log("evens:", evens);
```

运行:`node main.js`
输出:

```
arr: [ 1, 2, 3, 4 ] slice: [ 2, 3 ]
map get default: default
map has: true
map size: 2
set: [ 1, 2, 3 ]
obj: Alice
evens: [ 20, 40, 60 ]
```

> ⚠️ Java 思维陷阱 1:用 Object 当 HashMap——`obj["key"]` 的 key 只能是字符串/符号,且继承原型属性(安全坑);**真正的键值容器用 Map**。
>
> ⚠️ Java 思维陷阱 2:`slice` vs `splice`——slice 返回新数组(≈ subList 拷贝),splice 会**修改原数组**(删除/替换),别搞混。
>
> ⚠️ Java 思维陷阱 3:数组是对象——`typeof [] === "object"`;判断数组用 `Array.isArray(arr)`。

## 关键补充

### Map vs Object 选型

| 场景 | 用 |
|---|---|
| 动态键、非字符串键、频繁增删 | **Map**(性能好,保序) |
| 固定结构、JSON 数据 | Object |
| 两者互转 | `Object.fromEntries(map)` / `new Map(Object.entries(obj))` |

### 常用操作速查

| 场景 | JavaScript |
|---|---|
| 排序 | `arr.sort((a, b) => a.age - b.age)`(注意:默认字典序!) |
| 去重 | `[...new Set(arr)]` |
| 分组 | `Map` 手动 / `Object.groupBy`(ES2024) |
| 求和 | `arr.reduce((s, n) => s + n, 0)` |
| 最大/最小 | `Math.max(...arr)` |
| 合并数组 | `[...a, ...b]` |
| 查找 | `arr.find(f)` / `arr.findIndex(f)` |
