# Node.js · 05 IO 与网络

> 锚点:Java 的 java.io/NIO/HttpClient/Jackson 对应 Node 的 fs(promises)/stream/http/https/JSON。
>
> 验证环境:Node 22.23.0(实测输出)。

**一句话:Node 的 IO 默认异步——fs 文件操作和网络都走事件循环 + libuv 线程池;JSON 是语言内建(JSON.stringify/parse)。**

## IO 对照表

| 场景 | Java | Node.js |
|---|---|---|
| 读文件(异步) | Files.readAllBytes(同步) | `await fs.promises.readFile(path)` |
| 写文件 | Files.write | `await fs.promises.writeFile(path, data)` |
| 同步读(仅启动期) | — | `fs.readFileSync`(禁止用于请求路径) |
| 流式读 | BufferedReader / Stream | `fs.createReadStream` / for await |
| JSON | Jackson / Gson | **JSON.stringify / JSON.parse(原生)** |
| HTTP 客户端 | HttpClient / OkHttp | 内置 `fetch`(Node 18+)/ axios / undici |
| HTTP 服务端 | Spring Boot / Netty | **Express / Fastify**(基于 http 模块) |
| 序列化 | protobuf / Java 序列化 | JSON / protobufjs |

## 完整对照示例(实测)

```js
const fs = require("fs/promises");

async function main() {
  await fs.writeFile("godoc-js-data.txt", "hello file");
  const content = await fs.readFile("godoc-js-data.txt", "utf-8");
  console.log("file:", content);
  await fs.unlink("godoc-js-data.txt");

  const user = { name: "Alice", age: 30 };
  const j = JSON.stringify(user);
  console.log("json:", j);
  const parsed = JSON.parse(j);
  console.log("unmarshal:", parsed.name, parsed.age);
}

main();
```

运行:`node main.js`
输出:

```
file: hello file
json: {"name":"Alice","age":30}
unmarshal: Alice 30
```

> ⚠️ Java 思维陷阱 1:同步文件 API(`readFileSync`)用在请求处理里——**阻塞事件循环,拖垮所有并发请求**;请求路径必须用 `fs.promises` 异步版。
>
> ⚠️ Java 思维陷阱 2:把 JSON 当「序列化库」——JS 对象与 JSON 是原生互转,`JSON.parse` 会静默吞掉未知字段(与 Jackson 默认行为不同,要校验用 zod 或手写检查)。
>
> ⚠️ Java 思维陷阱 3:大文件一次性 readFile——**内存翻倍**(字符串 + buffer),用 `createReadStream` + 管道(≈ InputStream 包装)。

## HTTP 客户端:内置 fetch(≈ HttpClient)

```js
// Node 18+ 内置 fetch(与浏览器同 API,零依赖)
const resp = await fetch("https://api.example.com/orders/1", {
  headers: { "Content-Type": "application/json" },
});
const order = await resp.json();   // ≈ Jackson 反序列化
if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
```

## HTTP 服务端:最小 http 模块(底层)

```js
const http = require("http");

const server = http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ hello: "world" }));
});
server.listen(8080);
```

- 这就是 Express/Fastify 的底层——生产直接用框架(见 07 模块)。

## 流式 IO(≈ Java Stream/Netty 心智)

```js
const { createReadStream } = require("fs");

// 大文件流式处理(内存恒定)
for await (const chunk of createReadStream("big.log")) {
  processLine(chunk);   // chunk 是 Buffer 片段
}
```

- 流是 Node 的底层抽象:HTTP 请求体、文件、进程输出都是流。
- Java 对应:InputStream/OutputStream 包装链,但 Node 的流与异步配合更紧密。
