# Node.js · 01 语言特性

> 锚点:Java 的「多线程 + JVM + 编译型强类型」对应 Node.js 的「单线程事件循环 + V8 + 动态类型 + 异步原生」。
>
> 验证环境:Node 22.23.0(实测输出)。

## 范式对比

| 维度 | Java | Node.js |
|---|---|---|
| 运行时 | JVM(多线程) | **V8 引擎,单线程事件循环 + libuv 线程池** |
| 类型系统 | 静态强类型 | **动态类型**(TS 可加静态层) |
| 执行方式 | 编译 → 字节码 → JIT | 源码直接执行(V8 JIT) |
| 并发模型 | 线程 + 锁 + 异步编排 | **单线程 + 异步回调 + 事件循环** |
| 内存管理 | 分代 GC(可调优) | V8 分代 GC(--max-old-space-size 可调) |
| 异步 | CompletableFuture / 响应式库 | **Promise / async-await(语言原生,一等公民)** |
| 模块 | Maven 坐标 + classpath | **CommonJS / ES Modules** |
| 生态 | 企业全家桶 | npm(最大软件仓库)+ 微框架 |

## 关键差异

### 1. 单线程事件循环(最重要的心智模型)

- **JS 代码永远跑在单线程上**(一个进程一个主线程)。
- 高并发从哪来?异步 IO:发起 IO 请求后主线程**不等待**,立刻处理下一个任务;IO 完成由 libuv 线程池(默认 4,可调 `UV_THREADPOOL_SIZE`)通知回调。
- 与 Java 对比:Java 一个线程处理一个请求(阻塞时线程挂起);Node 一个线程**交替处理所有请求**(阻塞时换下一个)。
- 推论:**任何同步阻塞代码都会卡死整个进程**(所有请求一起停)。

### 2. 动态类型 + TypeScript 补救

```js
let x = 1;
x = "now a string";   // 合法
```

- 与 Python 同类的动态类型;大项目用 TypeScript(编译期类型检查,≈ 接近 Java 的静态保证)。
- 2026 年的现实:新项目默认 TS,`Node 22+ 原生支持 TS`(type stripping)。

### 3. Promise / async-await 是语言原生

```js
const data = await fetch("https://api.example.com/orders/1");
// ≈ CompletableFuture 的语法糖,但更简单:Java 的 thenApply 链 → JS 的 await 顺序写
```

- Java 的异步要引入 CompletableFuture/响应式库;JS 从语言层面就是异步的。
- 心智转换:Java 的「同步方法 + 异常」→ JS 的「async 函数 + try/catch」几乎一一对应。

### 4. 模块体系:CJS 与 ESM 并存

```js
// CommonJS(传统,require)
const express = require("express");

// ES Modules(现代,import,Node 18+ 稳定)
import express from "express";
```

- Java 只有一个 import;JS 有两套(历史包袱),新项目用 ESM,老项目 CJS 居多。
- 注意:`package.json` 的 `"type": "module"` 决定默认模式。

### 5. 语言细节对照

| 特性 | Java | JavaScript |
|---|---|---|
| 变量 | `int x = 1;` | `let x = 1;` / `const`(常量绑定) |
| 空值 | null / Optional | `null` / `undefined`(两套!) |
| 相等 | `==` 值比较 | **`===` 严格相等**(`==` 会类型转换,勿用) |
| 函数 | 方法/匿名类 | **函数是一等公民**(可传递/返回) |
| 类 | class 继承 | class(语法糖,底层原型链) |
| 接口 | interface | 无(TS 有 interface/type) |
| 泛型 | 编译期 | 无(TS 有) |
| main 入口 | public static void main | `node file.js` 直接跑 |

## 小结

Node 对 Java 开发者的核心冲击:**单线程 + 一切皆异步**。放弃「多线程并发」的默认思维,换成「事件循环 + 异步编排」,是学 Node 的第一课也是最重要一课(详见 04 模块)。
