# Node.js · 11 学习路径

> 锚点:给 Java 开发者的 7 天 Node.js 上手路线(基于本仓库模块)。
>
> 验证环境:纯文档;前置要求:已装 Node 22+(见 languages/nodejs/README.md)。

## 7 天上手路线

| 天 | 任务 | 产出(可自检) | 用到的模块 |
|---|---|---|---|
| D1 | 装 Node + npm init + hello world | `node app.js` 跑通;理解 package.json | README |
| D2 | 语法对照:let/const/箭头/解构/async-await | 用 JS 重写一个 Java 小工具(含异步) | 02 |
| D3 | 数据结构:Array/Map/Set + 高阶函数 | 实现一个 JSON 数据处理管线 | 03 |
| D4 | **Event Loop 心智**:Promise.all/race + 异步编排 | 用 Promise.all 并行拉 3 个 API 并聚合 | 04 |
| D5 | IO + 测试:fs/JSON/fetch + Jest | 给 D2-D4 写 Jest 测试(含异步用例) | 05、06 |
| D6 | 生产框架:Express/Fastify + zod | 写 CRUD API(参考 examples/nodejs-order-service) | 07 |
| D7 | 部署:pm2 集群 + Dockerfile + prom-client | 多实例运行,curl /metrics 看得到指标 | 08、09 |

**验收标准(D7 结束)**:独立完成「带并发扣减的订单服务」的编写、测试、集群部署、监控——即 `examples/nodejs-order-service` 全过程。

## 实战项目建议(顺序递进)

1. **CLI 工具**:文件批量处理(练 fs + 异步)
2. **API 聚合服务**:并发拉多个上游 API 聚合(练 Promise.all + fetch)
3. **实时推送**:SSE/WebSocket 服务(练 Node 强项)
4. **订单服务**:CRUD + 并发扣减 + 多实例(练生产形态,即 examples/ 契约)

## 常见问题

| 问题 | 答案 |
|---|---|
| 学 Node 要多久 | JS 语法 2-3 天(有 Java 基础);Event Loop 心智 1 周;生产熟练 1 月 |
| Node 能替代 Java 吗 | 场景不同:Node 强在 IO 密集/实时/BFF;Java 强在复杂业务/计算/生态成熟度 |
| 一定要学 TS 吗 | 新项目强烈建议(类型安全,大项目刚需);Node 22 原生支持 TS |
| 单线程会不会不够用 | IO 密集场景异步模型效率极高;CPU 密集用 worker_threads/多实例 |
