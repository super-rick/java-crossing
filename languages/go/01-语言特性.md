# Go · 01 语言特性

> 锚点:Java 的「面向对象 + JVM + 分代 GC」对应 Go 的「组合式设计 + 静态二进制 + 并发 GC」。
>
> 验证环境:Go 1.26.7 / Windows 11(git-bash),示例均为实测输出。

## 范式对比

| 维度 | Java | Go |
|---|---|---|
| 编程范式 | 面向对象(类继承/接口/多态) | 过程式为主 + 组合 + 接口(无继承) |
| 设计哲学 | 框架驱动、约定优于配置 | **简单、显式、标准库优先** |
| 面向对象 | class 继承体系 | struct + 方法(接收者),组合代替继承 |
| 接口 | 显式 implements | **隐式实现(duck typing)**,无需声明 |
| 泛型 | 1.5 起,类型擦除 | 1.18 起,完整泛型(可比较约束等) |
| 空值 | null + Optional | nil(无 Optional,显式检查) |
| 错误处理 | 异常 try/catch(可抛到调用栈上层) | **错误作为返回值**(error 类型,显式处理) |

## 关键差异

### 1. 没有继承:组合 + 接口是全部

Go 没有 `extends`。复用靠「结构体嵌入(embedding)」+「接口(隐式)」。

- 结构体嵌入 ≈ 组合式继承:内嵌类型的方法被提升到外层。
- 接口是**鸭子类型**:类型只要实现了接口的所有方法,就自动满足接口,不需要 `implements` 声明。

实测示例(接口隐式实现):

```go
package main

import "fmt"

type Speaker interface {
	Speak() string
}

type Dog struct{}

func (d Dog) Speak() string { return "Woof" } // 无需显式 implements

type Robot struct{}

func (r Robot) Speak() string { return "Beep" }

func main() {
	var s Speaker = Dog{}
	fmt.Println(s.Speak())
	s = Robot{}
	fmt.Println(s.Speak())
}
```

运行:`go run main.go`
输出:

```
Woof
Beep
```

> ⚠️ Java 思维陷阱:在 Go 里找 `implements` 关键字或「接口继承接口」的层级设计——Go 的接口设计目标是「小接口 + 隐式满足」,Java 式的大接口继承树在 Go 里是反模式。

### 2. 编译与运行时

| 维度 | Java | Go |
|---|---|---|
| 编译 | javac → 字节码 → JVM JIT | go build → **单个静态二进制**(AOT) |
| 运行时 | JVM(需要 JRE,启动预热) | 无运行时(直接执行,毫秒启动) |
| 交叉编译 | 需各平台 JDK/工具 | GOOS/GOARCH 一行交叉编译 |
| 依赖形态 | classpath/JAR 一堆文件 | 一个文件,零依赖 |

### 3. 内存管理

| 维度 | Java | Go |
|---|---|---|
| GC | 分代 G1/ZGC,大量调优参数 | **并发标记清除,全自动,基本不调** |
| 调优 | -Xmx/-XX: 系列 | GOMEMLIMIT(1.19+)+ GOGC(默认足够) |
| 对象分配 | 堆为主,逃逸分析优化 | 栈分配 + 逃逸分析,GC 压力更小 |
| 内存上限 | 堆 + 堆外 | 进程内存(运行时自动管理) |

### 4. 语言细节对照

| 特性 | Java | Go |
|---|---|---|
| 变量 | `int x = 1;` | `x := 1`(类型推导)或 `var x int = 1` |
| 常量 | `static final` | `const`(编译期) |
| 包 | package + import(类路径) | package + import(模块路径) |
| 可见性 | public/private/protected | **大写导出/小写私有**(无 protected) |
| main 入口 | public static void main | `func main()`(package main) |

### 5. 生态定位

- Java 生态:企业级全家桶(Spring 统治)。
- Go 生态:**标准库极强**(net/http、json、crypto、io 都是标准库),第三方框架「小而精」,没有 Spring 式全家桶——这是特性,不是缺陷。

## 小结

学 Go 语言特性,核心是接受三件事:**没有继承、没有异常、没有 JVM**。这三样是 Java 程序员的舒适区,也是 Go 对照价值最大的地方——理解之后,你会明白 Go 的每个设计决策都在为「简单 + 可部署性 + 高并发」服务。
