# Go · 03 数据结构

> 锚点:Java 集合框架(List/Map/Set/Queue)逐项对应 Go 的内置数据结构。
>
> 验证环境:Go 1.26.7 / Windows 11(git-bash),示例均为实测输出。

## 数据结构对照表

| Java | Go | 说明 |
|---|---|---|
| ArrayList | `[]T`(slice) | 动态数组,append 扩容 |
| LinkedList | `container/list` | 极少用(Go 惯例直接 slice) |
| HashMap | `map[K]V` | 内置,非并发安全 |
| HashSet | `map[T]struct{}` | Go 无 Set,用 map 模拟(空 struct 零内存) |
| TreeMap | 无(第三方 sortedmap) | 排序场景用 sort.Slice 处理 slice |
| ConcurrentHashMap | `sync.Map` | 读多写少优化;否则 Mutex + map |
| ArrayDeque/Queue | 无内置队列 | 惯例:channel 或 slice 实现 |
| Stack | 无内置栈 | slice 模拟(push=append, pop=[:len-1]) |
| 字符串 | string(不可变,UTF-8) | bytes.Buffer 拼接 |

## 核心类型详解

### 1. slice ≈ ArrayList(Go 的日常主力)

```go
package main

import "fmt"

func main() {
	// slice ≈ ArrayList(动态数组)
	nums := []int{1, 2, 3}
	nums = append(nums, 4, 5)
	fmt.Println("slice:", nums)

	// 切片视图:slice 是数组视图(≈ Java 的 subList 语义,共享底层)
	sub := nums[1:4]
	fmt.Println("sub:", sub)

	// map ≈ HashMap
	m := map[string]int{"a": 1, "b": 2}
	m["c"] = 3
	if v, ok := m["a"]; ok {
		fmt.Println("m[a] =", v)
	}
	delete(m, "b")
	fmt.Println("len:", len(m))

	// range 遍历 map(无序)
	for k, v := range m {
		fmt.Println("kv:", k, v)
	}
}
```

运行:`go run main.go`
输出:

```
slice: [1 2 3 4 5]
sub: [2 3 4]
m[a] = 1
len: 2
kv: a 1
kv: c 3
```

> ⚠️ Java 思维陷阱 1:slice 是「视图」不是「副本」——`sub := nums[1:4]` 修改 sub 会影响 nums(共享底层数组,和 Java 的 `subList` 语义一致但更隐蔽)。要独立副本用 `append([]T{}, nums...)`。
>
> ⚠️ Java 思维陷阱 2:`append` 返回新 slice,必须接住返回值:`nums = append(nums, x)`。不接返回值是常见 bug 来源(扩容时原 slice 失效)。

### 2. map ≈ HashMap(核心差异:不存在即零值)

```go
m := map[string]int{"a": 1}
v := m["不存在"] // 返回 0,不报错!
v, ok := m["不存在"] // ok=false,可判断是否存在
```

- Java:`m.get(k)` 返回 null,可能 NPE。
- Go:读取不存在的 key 返回**零值**(int→0,string→"",struct→空),不报错;判断存在用双返回值 `v, ok := m[k]`。
- **并发安全**:map 并发读写会直接 panic(不是崩溃在脏数据,是运行时检测到并发写直接 fatal)。多 goroutine 访问必须 `sync.Mutex` 或 `sync.Map`。

### 3. 集合(Set)模拟

```go
set := make(map[string]struct{}) // struct{} 零内存
set["a"] = struct{}{}
if _, ok := set["a"]; ok {
	fmt.Println("a exists")
}
delete(set, "a")
```

### 4. 其他常用

| 场景 | Go 写法 |
|---|---|
| 排序 | `sort.Ints(nums)` / `sort.Slice(users, func(i, j int) bool { return users[i].Age < users[j].Age })` |
| 反转 | 手写循环(标准库无内置) |
| 去重 | map 去重后转 slice |
| 最大/最小 | 手写循环(无 Math.max/min) |
| 字符串分割 | `strings.Split(s, ",")` |
| JSON 序列化 | `encoding/json`: `json.Marshal(obj)` / `json.Unmarshal(data, &obj)` |
