# Go · 02 基础语法

> 锚点:Java 的语法体系(变量/控制流/方法/类/异常)逐项对应 Go 的写法。
>
> 验证环境:Go 1.26.7 / Windows 11(git-bash),示例均为实测输出。

## 语法对照表

| 特性 | Java | Go | 差异要点 |
|---|---|---|---|
| 变量声明 | `int x = 1;` | `x := 1` 或 `var x int = 1` | `:=` 推导类型;声明了必须用(否则编译错) |
| 常量 | `static final int MAX = 10` | `const MAX = 10` | Go 常量编译期求值,可无类型 |
| if | `if (a > b) { }` | `if a > b { }` | **无括号**;条件前可带语句 `if v, err := f(); err == nil { }` |
| for | `for (int i=0;i<n;i++)` / `while` / `for(;;)` | 只有 `for`,三种形态 | 无 while/do-while |
| switch | `switch(x){ case 1: ...; break; }` | `switch x { case 1: ... }` | **自动 break**;case 可多值 `case 1, 2:` |
| 函数 | 方法需在类中 | 顶层 `func` + 多返回值 | 方法 = 函数 + 接收者 |
| 多返回值 | 无(用对象/异常) | **原生支持** `func f() (int, error)` | Go 招牌特性 |
| 错误处理 | try/catch/finally + 异常类型 | 错误作为返回值 + if 判断 | 无异常机制(有 panic/recover,仅用于不可恢复错误) |
| 类/对象 | class + new | struct + 字面量 | 无构造器,工厂函数惯例 |
| 继承 | extends/implements | 结构体嵌入 + 接口 | 组合代替继承 |
| 泛型 | `<T>` 擦除 | `[T any]` 完整泛型(1.18+) | 写法:方括号 |
| 包 | import java.util.* | import "fmt" | 模块化,GOPATH/模块路径 |
| 指针 | 无(引用传递) | 有指针(不能运算) | `&` 取址,`*` 解引用 |

## 完整对照示例(实测)

### 1. 变量 / 控制流 / 多返回值 / 错误处理

```go
package main

import (
	"errors"
	"fmt"
)

// 多返回值 + 错误作为返回值(Go 惯例,区别于 Java 异常)
func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, errors.New("division by zero")
	}
	return a / b, nil
}

func main() {
	// 短变量声明 := 与显式声明
	name := "Go"
	var version string = "1.26"

	// for 是唯一循环:三种形态
	for i := 0; i < 3; i++ {
		fmt.Println("for-i:", i)
	}
	n := 0
	for n < 2 {
		n++
		fmt.Println("for-while:", n)
	}

	// switch:无需 break,默认自动跳出
	switch name {
	case "Go":
		fmt.Println("switch: Go lang")
	default:
		fmt.Println("other")
	}

	// 错误处理:if + err 判断
	if v, err := divide(10, 2); err == nil {
		fmt.Println("10/2 =", v)
	}
	if _, err := divide(1, 0); err != nil {
		fmt.Println("error:", err)
	}

	_ = version
}
```

运行:`go run main.go`
输出:

```
for-i: 0
for-i: 1
for-i: 2
for-while: 1
for-while: 2
switch: Go lang
10/2 = 5
error: division by zero
```

### 2. 结构体 / 方法(接收者)/ 指针

```go
package main

import "fmt"

type User struct {
	Name string
	Age  int
}

// 方法:接收者(receiver),等价于 Java 的实例方法
func (u *User) Birthday() {
	u.Age++
}

// 值接收者:不修改原对象
func (u User) Describe() string {
	return fmt.Sprintf("%s(%d)", u.Name, u.Age)
}

func main() {
	u := User{Name: "Alice", Age: 30} // 结构体字面量
	u.Birthday()
	fmt.Println("after birthday:", u.Describe())

	// 指针:显式 & 与 *(Go 指针不能运算,比 C 安全)
	p := &u
	p.Age = 99
	fmt.Println("via pointer:", u.Age)
}
```

运行:`go run main.go`
输出:

```
after birthday: Alice(31)
via pointer: 99
```

> ⚠️ Java 思维陷阱 1:变量声明了必须使用,否则编译失败——Java 只是警告,Go 直接编译错误。写完代码第一件事跑 `gofmt` + `go vet`。
>
> ⚠️ Java 思维陷阱 2:用 try/catch 思维写 Go——Go 的错误是「值」,必须显式处理(`if err != nil`);忽略错误用 `_`,没有「不处理」的语法糖。panic/recover 只用于不可恢复错误(数组越界等),不是业务错误处理工具。
>
> ⚠️ Java 思维陷阱 3:Java 的引用传递让「对象改了没改」靠约定;Go 显式区分值接收者(不改)与指针接收者(改),`User` 传值会拷贝,大结构体记得用指针。

## 常见写法对照

| 场景 | Java | Go |
|---|---|---|
| 字符串拼接 | `String.format("%s-%d", s, i)` | `fmt.Sprintf("%s-%d", s, i)` |
| 数组遍历 | `for (String s : list)` | `for _, s := range list` |
| 条件赋值 | 三目?无,if-else | if-else(无三目) |
| 判空 | `if (x == null)` | `if x == nil` |
| 类型转换 | `(String) obj` | `v.(string)`(类型断言)+ `strconv` 包 |
| 注释 | `//` 与 `/* */` + Javadoc | `//` 与 `/* */`(无文档注解,文档注释 `// 函数名 以注释开头`) |
