# Go · 11 学习路径

> 锚点:给 Java 开发者的 7 天 Go 上手路线(基于本仓库模块)。
>
> 验证环境:纯文档;前置要求:已安装 Go 1.24+(见 languages/go/README.md)。

## 7 天上手路线

| 天 | 任务 | 产出(可自检) | 用到的模块 |
|---|---|---|---|
| D1 | 装工具链 + go mod 概念 + 跑通 hello world | `go run` 出结果;理解 go.mod | README |
| D2 | 语法对照:变量/控制流/函数/结构体/指针 | 用 Go 重写一个 Java 小工具(如文件统计) | 02 |
| D3 | 数据结构:slice/map 全部常用操作 | 实现 LRU 缓存(用 map+slice) | 03 |
| D4 | **并发:goroutine/channel/select/Mutex** | 实现并发 worker 池 + 并发计数器(跑 go test -race) | 04 |
| D5 | IO + 测试:文件/JSON/http + 表驱动测试 | 给 D3/D4 的代码补表驱动测试,覆盖率 ≥80% | 05、06 |
| D6 | 生产框架:Gin + GORM 组合栈 | 用 Gin 写 CRUD API(参考 examples/go-order-service) | 07 |
| D7 | 部署:交叉编译 + 多阶段 Dockerfile + pprof | 构建静态二进制 + 镜像,curl /debug/pprof 看得到 | 08、09 |

**验收标准(D7 结束)**:能独立完成「一个带并发扣减的订单服务」的编写、测试、打包、部署、监控接入——即本仓库 `examples/go-order-service` 的全过程。

## 实战项目建议(顺序递进)

1. **命令行工具**:文件批量重命名/日志解析(练语法 + 标准库)
2. **并发爬虫**:限并发抓取 + 汇总(练 goroutine/channel/errgroup)
3. **订单服务**:CRUD + 并发扣库存 + 幂等(练生产形态,即 examples/ 契约)
4. **中间件练习**:给服务加 Prometheus 指标 + pprof + 优雅停机(练监控运维)

## 常见问题

| 问题 | 答案 |
|---|---|
| 学 Go 要多久 | 语法 2-3 天;并发心智 1-2 周;生产熟练 1-2 月(有 Java 基础) |
| 需要先学 C 吗 | 不需要,但懂指针概念有助理解(Go 指针不能运算,安全) |
| Go 能做 Java 做不了的吗 | 不是能不能,是形态不同:静态二进制 + 毫秒启动 + 低内存,云原生场景优势大 |
| 学了 Go 会不会忘 Java | 不会;两个心智模型并存,架构师视角反而更完整 |
